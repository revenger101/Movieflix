# MovieFlix - A Netflix Clone

MovieFlix is a static website clone of Netflix, designed with HTML, CSS, and JavaScript. It replicates the core features of Netflix, providing a seamless and visually appealing movie and TV show browsing experience.

## Features

- Responsive design for optimal viewing on all devices.
- Movie and TV show display with thumbnail images and titles.
- Interactive elements with hover effects.
- Simple navigation to browse through different genres.
- Light and dark mode (optional, if you’ve implemented this feature).

## Technologies Used

- **HTML**: Used to create the structure of the website.
- **CSS**: Used for styling and layout of the website. It includes custom styles and responsive media queries.
- **JavaScript**: Used to add interactivity (such as hover effects, button clicks, etc.).
